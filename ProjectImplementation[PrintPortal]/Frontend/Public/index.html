Print requests

How to use this page
  1. Pick an account with Signed in as at the top. Customers only see their own requests; the coordinator sees everyone's.
  2. Filter by status, category or priority to find outstanding work. The list updates straight away.
  3. Open a request by clicking its ID to see its details and status history.
  4. Need something printed? Choose New request in the menu.
  5. New here? Choose Take the tour in the menu for a guided walkthrough.

Request

How to use this page
  1. The details card shows what was requested, its current status and who is working on it.
  2. Assign a staff member, then use Move to… to advance one step at a time: Submitted → Assigned → In Progress → Completed. A request needs an assignee before it can be Assigned.
  3. Only the coordinator can assign work or change the status. Check back here to follow progress.
  4. The status history lists every change, when it happened and which account made it.
